PINK & WHITE FRIENDSHIP MESSAGE WEBSITE

1. Extract this ZIP.
2. Open index.html in a browser to preview it.
3. Edit the message in index.html inside the <div class="message-text"> section.
4. To publish free: upload index.html, style.css, and script.js to a GitHub repository.
5. In GitHub, open Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. After publishing, test the link on Android/iPhone before sharing it.

The design uses a simple pink-and-white palette and is responsive for mobile browsers.
